# @omuso/react-reader

React components and hooks for building reading experiences on top of [OMUSO](../omuso).

> ⚠️ Work in progress — not yet published to npm.

## Development

From the repo root:

```
bun install
bun --filter @omuso/react-reader dev
bun --filter @omuso/react-reader test
bun --filter @omuso/react-reader build
```
